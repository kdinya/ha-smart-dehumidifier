# HA Smart Dehumidifier

Home Assistant інтеграція для керування осушувачем вологого приміщення
(звичайний вентилятор через розумний вимикач) + картка для Lovelace з тим
самим дизайном, що й у оригінальній `my-dehumidifier`.

Раніше вся логіка трималась на картці + 5 допоміжних об'єктах + 4
автоматизаціях + 1 скрипті. Тепер усе це — всередині інтеграції, окремих
helper'ів і автоматизацій створювати не потрібно.

## Паралельна робота зі старою карткою `my-dehumidifier`

Ця інтеграція повністю ізольована від старої конфігурації:

- окремий домен `ha_smart_dehumidifier` (усі нові сутності — `humidifier`,
  `sensor`, `switch`, `button`, `number`);
- усі entity_id нових сутностей отримують префікс **`smart_`** і ніколи не
  перетнуться з існуючими сутностями старої версії;
- окремий шлях фронтенду `/ha_smart_dehumidifier_files/...` і окремий тег
  картки `custom:ha-smart-dehumidifier` — стару картку `custom:my-dehumidifier`
  не чіпає;
- старі helper'и, автоматизації та скрипт ця інтеграція не читає і не змінює.

Стару картку й нову інтеграцію можна тримати ввімкненими одночасно під час
налаштування/звірки, а стару прибрати (картку, helper'и, автоматизації,
скрипт), коли переконаєшся, що нова працює так само.

## Встановлення через HACS

1. HACS → Custom repositories → додати цей репозиторій (тип: Integration).
2. Встановити "HA Smart Dehumidifier", перезапустити Home Assistant.
3. Settings → Devices & services → Add integration → **HA Smart Dehumidifier**.
4. Вказати:
   - **Вимикач вентилятора** — реальний `switch`, який фізично вмикає вентилятор.
   - **Датчик вологості** у приміщенні з осушувачем.
   - **Датчик абсолютної вологості** сусіднього приміщення (наприклад, сенсор
     інтеграції Thermal Comfort).
   - **Датчик температури** того ж сусіднього приміщення.
5. Інтеграція автоматично створить: `humidifier`, `sensor` (статус +
   рекомендована вологість), `switch` (авто-режим), `button` (ручний режим),
   `number` × 5 (дельта, мін./макс. вологість, тривалість/пауза таймера).

## Додавання картки

Картка реєструється автоматично — ресурс Lovelace вручну додавати не
потрібно. У режимі YAML достатньо вказати тип і головну сутність:

```yaml
type: custom:ha-smart-dehumidifier
entity: humidifier.smart_xxx
```

Все інше (`fan_entity` та решта) обирається через **візуальний
редактор картки** (вкладка "Сутності" 🔗) — не треба нічого вписувати
вручну. Сенсори статусу/рекомендованої вологості, перемикач авто-режиму,
кнопка ручного режиму і number-сутності підхоплюються карткою автоматично
за entity_id головної сутності — вказувати їх окремо потрібно лише якщо ти
змінив їхні entity_id вручну.

Обов'язково через редактор потрібно вибрати лише:

- **Осушувач** (`entity`) — головна сутність інтеграції;
- **Вимикач вентилятора** (`fan_entity`) — реальний фізичний вимикач.

Усі візуальні налаштування (розкладка, дуга, кольори, ефекти, шрифт
7-segment тощо) редагуються там само, як і раніше.

## Налаштування розрахунку

Значення нижче можна змінювати двома способами: живо через шестерню на
самій картці (як і в оригіналі) — зберігаються між перезапусками; або
одноразово як стартові — Settings → HA Smart Dehumidifier → Configure.

| Параметр | Значення за замовчуванням |
|---|---|
| Дельта абсолютної вологості | 3.75 г/м³ (робочий діапазон 3.5–4) |
| Мін. рекомендована вологість | 65% |
| Макс. рекомендована вологість | 85% |
| Гістерезис (толерантність, лише в Options) | 5% |
| Тривалість ручного режиму | 20 хв |
| Пауза після ручного режиму | 20 хв |

Інтеграція має вбудований анти-деренчання захист (anti short-cycle): якщо
вологість або ціль коливаються прямо на межі гістерезису, реле вентилятора
все одно не клацатиме частіше, ніж раз на 90 секунд.

## Якщо картка не з'являється (Custom element doesn't exist)

1. Перевір, що інтеграція реально завантажилась: Settings → System → Logs →
   пошук "ha_smart_dehumidifier". Якщо бачиш помилку реєстрації ресурсу —
   там же буде вказано, що зробити.
2. Відкрий картку в браузері (F12 → Network), онови сторінку і перевір
   запит `/ha_smart_dehumidifier_files/index.js` — має бути **200**, а не
   404. Якщо 404 — інтеграція не завантажилась (перевір логи) або HA
   потрібно повністю перезапустити (не reload, а restart) після
   встановлення через HACS.
3. Жорстко онови кеш браузера (Ctrl+Shift+R / Cmd+Shift+R).
4. Якщо нічого з вищого не допомогло — додай ресурс вручну: Settings →
   Dashboards → ⋮ → Resources → Add resource → URL
   `/ha_smart_dehumidifier_files/index.js`, тип **JavaScript Module**.
